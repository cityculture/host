# City Culture - Host Portal

Official host portal for City Culture (`host.cityculture.in`), an open event listing and ticketing platform across India.

## Features

- **Host Authentication & Profile Management**: Secure login and profile verification for event hosts.
- **Event Creation & Management**: Create, edit, and publish offline and online events, schedule agendas, set capacities, and manage tiers.
- **Flexible Ticketing & Payouts**: Support for City Culture's inbuilt proprietary ticketing system (Razorpay integration) or redirection to custom UPI IDs, payment QR codes, and external ticketing links.
- **Attendee Tracking & Check-in**: Real-time ticket scanning, QR check-ins, attendee lists, and ticket status monitoring.
- **Financial & Analytics Dashboard**: Real-time sales telemetry, ticket breakdowns, and payment reconciliation.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3004](http://localhost:3004) with your browser to see the result.
